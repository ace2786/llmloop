# agent-sessions

本目录存放**本 302 毕设项目相关**的、与 AI 编程助手的对话记录。

## 内容范围

**只包含 llmloop 项目（大模型应用自动调优系统）相关的对话。**

不含：其他课程作业、私人项目、生活类提问。

## 目录结构

```
agent-sessions/
├── README.md              ← 本文件
├── 2026-11-11/
│   └── 01_重排序实验.md
├── 2026-11-12/
│   └── ...
```

命名：`<序号>_<主题>.md`，序号用于排序。

## 怎么来的

用 WorkBuddy / CodeBuddy IDE 的分享功能导出：

1. 对话面板右上角 → 点「分享」，复制链接
2. 在浏览器打开该链接
3. `Ctrl+A` 全选 → `Ctrl+C` 复制
4. 粘贴到 `.md` 文件，用 `scripts/clean_session_md.py` 清理网页噪音

**说明**：当前工具不提供「一键保存到本地」的导出按钮，只有分享链接。
分享页是动态渲染的，无法用脚本直接抓取，所以采用「浏览器复制 → 清理」的方式。
**这是整理后的文本，不是工具的原始导出文件。**

## 为什么记录这些

老师要求：这些记录用于分析编程方法、提示词写法、出现的 bug，并给出针对性建议。

因此每份记录尽量保留：

- **提问的原话**（不要事后润色成「需求文档」）
- **AI 给了什么建议**
- **我采纳了什么、否决了什么、为什么**
- **最后产生了什么提交**

## 提醒

- 提交前检查一遍，确认没有私人信息、密钥、其他项目内容
- 对话里如果贴过 `.env` 或 API key，删掉再提交
