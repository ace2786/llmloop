## 三、这个差异说明了什么

### 现象

```
qwen（61%）：三个估计值几乎相同 → 方法之间没有分歧
GLM（96%）：IRT 估计 97%，p-IRT/gp-IRT 估计 80-82% → 差 17 点
```

### 解释

- **IRT**：直接用题目难度参数反推能力，对「小样本几乎全对」不做惩罚 → 容易高估
- **p-IRT / gp-IRT**：贝叶斯版本，会把估计「收缩」到先验分布 → 更保守
- **为什么中等水平没差异**：61% 接近先验均值，收缩不产生位移；96% 远离先验，收缩明显

**论文里 p-IRT / gp-IRT 的误差（1.6%）低于 IRT（2.4%），正是因为这种收缩效应
在「高分模型」上能防止高估。**

### 但要验证哪个准，需要「真实全量成绩」

**这是当前缺的一环。**
