## 四、每天的验收点（照着勾）

**题库（你）**

- [ ] 新题的标准答案来自文档原文，不是自己编的
- [ ] 每条带 `doc_location`（文件名 + 段落）
- [ ] 同一段落不要超过 3 道题（避免重复考点）
- [ ] 跑一次 `bash run.sh check` 不报错

**评测执行（后端）**

- [ ] `POST /apps/{id}/evaluate` 能对指定 split 的题跑一遍
- [ ] 每题记录：问题、模型回答、耗时、token 用量
- [ ] 200 题不会让请求超时（异步 + 轮询，或流式）
- [ ] 外部模型超时/报错时有重试，单题失败不影响整批

**前端**

- [ ] 停后端，页面报错，不显示任何假数字
- [ ] 搜索结果能跨页（证明不是本地过滤）
- [ ] 评测结果页的每个数字都来自 `GET /runs/{rid}`
